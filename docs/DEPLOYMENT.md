| `GOOGLE_CLIENT_SECRET` | *(Set manually — never commit to git)* |

## Vercel: Required Environment Variables

Set these in **Vercel Dashboard → datacrew → Settings → Environment Variables**:

| Variable | Value |
| :--- | :--- |
| `API_URL` | `https://datacrew-h98o.onrender.com` |

## Troubleshooting

| Symptom | Cause | Fix |
| :--- | :--- | :--- |
| Sign-up returns 500 | `API_URL` not set in Vercel | Add `API_URL=https://datacrew-h98o.onrender.com` in Vercel env vars |
| Google OAuth returns 502 | Render cold start or wrong redirect URI | Wait 30s for Render to wake, verify `GOOGLE_REDIRECT_URI` |
| `redirect_uri_mismatch` | Google Console not updated | Add production callback URL to Google Cloud Console |
| CORS errors | `ALLOWED_ORIGINS` missing Vercel domain | Update `ALLOWED_ORIGINS` in Render env |
